Quick setup

Choose a project to download a package for your platform or copy an installation command.

Gharmonize
  1. On Windows, download the Setup EXE. On Linux, download an AppImage or a package for your distribution.
  2. Run the installer on Windows. If you downloaded the AppImage on Linux, run the commands below in the folder where you saved it.
  3. To connect to your music library on Android, use the Gharmonize-Player-Client APK from the same release.
chmod +x ./Gharmonize-*.AppImage
./Gharmonize-*.AppImage

Install the latest release

.pkg.tar.zst Arch Linux, Manjaro, EndeavourOS

curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith("-x64.pkg.tar.zst")) | .browser_download_url' \
  | xargs -r sudo pacman -U

.deb Debian, Ubuntu, Linux Mint

curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith("-amd64.deb")) | .browser_download_url' \
  | xargs -r curl -fLo /tmp/gharmonize.deb \
  && sudo apt install /tmp/gharmonize.deb

.rpm Fedora and other RPM-based distributions

curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith(".rpm")) | .browser_download_url' \
  | xargs -r sudo dnf install -y

.AppImage Any x86-64 distribution. Saved to ~/Applications and opened.

mkdir -p ~/Applications \
  && curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith(".AppImage")) | .browser_download_url' \
  | xargs -r curl -fLo ~/Applications/Gharmonize.AppImage \
  && chmod +x ~/Applications/Gharmonize.AppImage \
  && ~/Applications/Gharmonize.AppImage

G-Hotspot
  1. Run the commands below with Node.js 24 or later.
  2. On the server, open http://127.0.0.1:8080/install. For remote setup, use the setup URL printed in the server console.
  3. Test in the default mock mode first. Configure the OPNsense integration to grant access to the guest network.
git clone https://github.com/G-grbz/G-Hotspot.git
cd G-Hotspot
npm start

Install the latest release

.zip Node.js 24 or newer. Unpacks the latest release into your home folder and starts the server.

curl -fsSL https://api.github.com/repos/G-grbz/G-Hotspot/releases/latest \
  | jq -r '.assets[] | select(.name | test("^G-Hotspot-v[0-9.]+\\.zip$")) | .browser_download_url' \
  | xargs -r curl -fLo /tmp/g-hotspot.zip \
  && unzip -oq /tmp/g-hotspot.zip -d ~ \
  && cd "$(ls -d ~/G-Hotspot-v* | sort -V | tail -n 1)" \
  && npm start

.apk Android app. Download it on the phone and open it; Android may ask you to allow installs from this source.
