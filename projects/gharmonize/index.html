Gharmonize

Download, convert, and tag media, then stream your music library to a browser or Android. This guide covers packaged desktop builds, Docker Compose, and Player setup.

Installation steps Try the Player demo GitHub Releases
Features Desktop installation Docker Compose deployment Environment variables Player and Android pairing

Features

  • Download media with yt-dlp, convert audio and video with FFmpeg, and edit metadata and cover art.
  • Rip DRM-free discs, prepare ringtones, and use hardware encoding when your system supports it.
  • Play your own library using Gharmonize Player in a browser, on an Android phone, or on Android TV.
  • Use supported music catalogs to find track metadata and match media sources.
Feature reference

Desktop installation

  1. From GitHub Releases, download the Windows Setup EXE, Linux AppImage, or the DEB, RPM, or Arch package for your distribution.
  2. Run the Windows installer or install the Linux package with your package manager. For AppImage, run the commands below from the download folder.
  3. Open Gharmonize. The packaged Electron app includes Node.js. On first launch, let Gharmonize finish preparing its media tools.
  4. Read the initial password from INITIAL_ADMIN_PASSWORD.txt and change it in Settings after signing in. The desktop profile is under ~/.config/Gharmonize/ on Linux and %APPDATA% on Windows, inside the Gharmonize folder.

Install the latest release

.pkg.tar.zst Arch Linux, Manjaro, EndeavourOS

curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith("-x64.pkg.tar.zst")) | .browser_download_url' \
  | xargs -r sudo pacman -U

.deb Debian, Ubuntu, Linux Mint

curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith("-amd64.deb")) | .browser_download_url' \
  | xargs -r curl -fLo /tmp/gharmonize.deb \
  && sudo apt install /tmp/gharmonize.deb

.rpm Fedora and other RPM-based distributions

curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith(".rpm")) | .browser_download_url' \
  | xargs -r sudo dnf install -y

.AppImage Any x86-64 distribution. Saved to ~/Applications and opened.

mkdir -p ~/Applications \
  && curl -fsSL https://api.github.com/repos/G-grbz/Gharmonize/releases/latest \
  | jq -r '.assets[] | select(.name | endswith(".AppImage")) | .browser_download_url' \
  | xargs -r curl -fLo ~/Applications/Gharmonize.AppImage \
  && chmod +x ~/Applications/Gharmonize.AppImage \
  && ~/Applications/Gharmonize.AppImage

Run from source on Linux

Install Node.js 22.12 or newer. Use npm run server in an installed checkout for the browser-only server on port 5174.

Source installation commands

git clone https://github.com/G-grbz/Gharmonize
cd Gharmonize
BUILD_ELECTRON=1 npm install
npm start

Docker Compose deployment

Use Docker Engine with the Compose plugin on a Linux host. The supplied stack pulls the official image from ghcr.io/g-grbz/gharmonize and serves the web interface.

Prepare a fresh installation

Docker directory setup commands

git clone https://github.com/G-grbz/Gharmonize
cd Gharmonize
sudo install -d -m 700 -o "$(id -u)" -g "$(id -g)" /opt/gharmonize
mkdir -p /opt/gharmonize/{uploads,outputs,temp,cache,cookies,local-inputs}
touch /opt/gharmonize/.env
chmod 600 /opt/gharmonize/.env

In the cloned checkout, save Compose values in .env. Replace the example user and group IDs with the output of id -u and id -g. Gharmonize reads its own optional settings from /opt/gharmonize/.env.

Compose environment example

PUID=1000
PGID=1000
PORT=5174
MUSIC_DIR=/opt/gharmonize/local-inputs

Start and check the service

Docker Compose start commands

docker compose config --quiet
docker compose pull
docker compose up -d
docker compose ps
  1. Open http://localhost:5174 on the host. To use YTLive, open /ytlive.html on the same server.
  2. Get the initial password from /opt/gharmonize/cache/INITIAL_ADMIN_PASSWORD.txt, change it in Settings, and then remove the one-time credential file.
  3. Preserve the cache volume and its encryption key across upgrades. For a remote deployment, use HTTPS and protect access to the published port.

For a pinned deployment, use a version tag from GHCR. For NVIDIA/NVENC or a source-built image, use the corresponding instructions in the Docker guide.

Docker options, upgrades and NVIDIA

Environment variables

All variables are optional; defaults are used when a value is left empty. Set them in .env or from the Settings panel. In Docker use the Compose environment; in the desktop app edit ~/.config/Gharmonize/.env on Linux or %APPDATA%/Gharmonize/.env on Windows. Restart after changing directory settings.

Detailed configuration reference with examples

Player and Android pairing

  1. In Gharmonize settings, enable Gharmonize Player and open /player/.
  2. Create the first Player account using your administrator credentials. Add folders in Administration → Libraries and scan them.
  3. Install the Gharmonize-Player-Client APK from GitHub Releases. Open device pairing in the web Player and scan the QR code from the Android app.
  4. For desktop LAN listening, enable the dedicated Player listener, normally on port 5175. Docker clients can use the existing published port, normally 5174.
