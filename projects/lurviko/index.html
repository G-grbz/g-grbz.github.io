Lurviko

A Qt Quick file manager for Linux with tabs, split panes, file previews and an Explore dashboard for your library. Use the native packages for deeper KDE network integration.

Installation steps GitHub Releases
Features Install on Linux First use and cloud accounts Build from source

Features

  • Browse with grid, list or Miller Columns, and use tabs, split panes, favorites and batch rename.
  • Preview photos and play music and video. Explore indexes selected media folders, and the player can show subtitles and chapters.
  • Browse Google Drive and OneDrive, use KDE KIO locations, and inspect Git status and history where supported.
  • Use encrypted local vaults and optional KWallet quick unlock. Keep recovery information in a separate secure location.
File views and desktop integration

Install on Linux

  1. Open GitHub Releases and choose a package for your x86-64 distribution. The AppImage requires glibc 2.39 or newer.
  2. Use the native package when you need extra KIO workers for SFTP, SMB or MTP. AppImage includes the common local and web workers.
  3. Pick one installation method below. After installing a native package, open Lurviko from the applications menu.

Install the latest release

yay Arch Linux and derivatives, with an AUR helper

yay -S lurviko

.pkg.tar.zst Arch Linux, Manjaro, EndeavourOS

curl -fsSL https://api.github.com/repos/G-grbz/Lurviko/releases/latest \
  | jq -r '.assets[] | select(.name | endswith("-x86_64.pkg.tar.zst")) | .browser_download_url' \
  | xargs -r sudo pacman -U

.deb Debian 13 (trixie)

curl -fsSL https://api.github.com/repos/G-grbz/Lurviko/releases/latest \
  | jq -r '.assets[] | select(.name | endswith("_amd64.deb")) | .browser_download_url' \
  | xargs -r curl -fLo /tmp/lurviko.deb \
  && sudo apt install /tmp/lurviko.deb

.rpm Fedora 43 and newer

curl -fsSL https://api.github.com/repos/G-grbz/Lurviko/releases/latest \
  | jq -r '.assets[] | select(.name | endswith(".x86_64.rpm")) | .browser_download_url' \
  | xargs -r sudo dnf install -y

.AppImage Any distribution with glibc 2.39 or newer. Saved to ~/Applications and opened.

mkdir -p ~/Applications \
  && curl -fsSL https://api.github.com/repos/G-grbz/Lurviko/releases/latest \
  | jq -r '.assets[] | select(.name | endswith(".AppImage")) | .browser_download_url' \
  | xargs -r curl -fLo ~/Applications/Lurviko.AppImage \
  && chmod +x ~/Applications/Lurviko.AppImage \
  && ~/Applications/Lurviko.AppImage

Linux commands need curl and jq. They always download the latest release from GitHub.

Lurviko AppImage commands

chmod +x ./Lurviko-*.AppImage
./Lurviko-*.AppImage

When FUSE is unavailable, run the executable with APPIMAGE_EXTRACT_AND_RUN=1 set.

First use and cloud accounts

  1. Choose your preferred file view and turn on a split pane if you want to work in two folders side by side.
  2. In Explore, add media roots you want indexed. Use the player for supported videos, photos and audio files.
  3. For Google Drive or OneDrive, create or obtain the provider’s OAuth application credentials, add them in Lurviko and sign in through the provider in your browser.
  4. For encrypted folders, create a vault and choose whether to enable KWallet quick unlock. Keep its recovery key private if you create one.

Build from source

Install Qt 6.8+, KDE Frameworks 6, OpenSSL 3.2+, CMake 3.21+, Ninja and a C++17 compiler. Use the dependency list for your distribution in the official instructions.

Lurviko build commands

git clone https://github.com/G-grbz/Lurviko.git
cd Lurviko
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 4
./build/lurviko

Lurviko user installation

cmake --install build --prefix "$HOME/.local"
update-desktop-database "$HOME/.local/share/applications"

Keep $HOME/.local/bin in your desktop session’s PATH for the user-installed launcher.
