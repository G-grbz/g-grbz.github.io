G-TMCE

Create and extract Matroska files using MKVToolNix and FFmpeg. Set track languages and defaults, preserve source timing, and add TMDB artwork and metadata.

Installation steps GitHub Releases
Features Install on Linux or Windows MKV and season workflows AI subtitles Settings and TMDB

Features

  • Build MKV files from video, audio, subtitles, chapters and attachments without writing mkvmerge commands.
  • Extract selected tracks and attachments for editing or remuxing. Keep automatically saved timing files with the source tracks.
  • Extract an entire TV season in one batch. Edit audio and subtitle tracks per episode, then remux the season in a single run.
  • Translate existing subtitles with local AI. Generate subtitles from an audio track in its original language, then translate them into the language you choose.
  • Apply audio delays, choose default audio and subtitle languages, and handle forced or SDH subtitles.
  • Fetch TMDB covers and artwork, generate tags, and prepare chapters and filenames from the title.

Install on Linux or Windows

  1. On Windows, download the x64 EXE from GitHub Releases and open it.
  2. On Linux, download the x86-64 AppImage and run the commands below from its folder. Arch users can install the AUR package instead.
  3. Allow internet access on first use so G-TMCE can prepare MKVToolNix and FFmpeg. Existing tools remain available for offline operation.

Install the latest release

yay Arch Linux and derivatives, with an AUR helper

yay -S g-tmce

.AppImage Any x86-64 distribution. Saved to ~/Applications and opened.

mkdir -p ~/Applications \
  && curl -fsSL https://api.github.com/repos/G-grbz/G-TMCE/releases/latest \
  | jq -r '.assets[] | select(.name | endswith(".AppImage")) | .browser_download_url' \
  | xargs -r curl -fLo ~/Applications/G-TMCE.AppImage \
  && chmod +x ~/Applications/G-TMCE.AppImage \
  && ~/Applications/G-TMCE.AppImage

.exe No installation needed. Download it and run it.

MKV and season workflows

Extract selected tracks

  1. Select the source MKV and wait for its tracks to be scanned. Use Scan MKV to refresh the list if needed.
  2. Select the video, audio, subtitles or attachments you want and choose Extract Selected.
  3. Keep the extracted folder together when remuxing. The workspace can contain a .gtmce/ directory and source timestamp files.

Add metadata and remux

  1. Choose the track folder. Enter your TMDB API key, select movie or TV, and choose artwork and tag languages.
  2. Use Find ID to confirm the title. Choose the default audio and subtitle tracks, then use Download Artwork/Tags if you want TMDB assets.
  3. Select Create MKV.

Process an entire TV season

  1. Select the season folder and choose Extract Folder. G-TMCE extracts the selected tracks into a separate workspace for each episode.
  2. Enable Add tracks before muxing and choose Mux Extracted Folder. Use the episode tabs to add audio or subtitle tracks, choose which tracks to include, reorder them, or adjust their delays.
  3. Confirm the batch. G-TMCE creates a separate MKV for each episode using that episode’s settings.

AI subtitles

  • To translate an existing subtitle, open Create Subtitle from the main window. Select an SRT, ASS, SSA, or VTT file, choose the source and target languages, and press Start. The translation keeps the cue timing and is saved as a separate file.
  • To generate subtitles from audio, choose an audio track in Adjust Audio and select Create Subtitle. Whisper transcribes the dialogue in its original language and writes an SRT file.
  • To produce translated subtitles from an audio track, choose AI Translate in the same window and select a target language. G-TMCE reuses the generated SRT when available and transcribes the audio first when needed.

Models are downloaded on first use. Transcription and translation run on your device. Translation is in beta, so review the subtitles before using them.
